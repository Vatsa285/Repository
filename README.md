HELLO WELCOME TO OUR EMOTION DETECTION AI MODEL

Steps to run the model

1.Install required dependencies\n

2.Open two terminals 

3.Run main.py which loads AI-model and connects to fast API in one terminal

4.Traverse to the React directory using 'cd' command in second terminal

5.Run 'nm start' in the above mentioned directory to launch the frontend page

6.Press the 'Start' button to record the audio

7.Press the 'Stop' button when done with talking and press 'Detect emotion' to analyse the emotion
